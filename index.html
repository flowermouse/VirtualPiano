音量

提示：键盘 4 行共 40 个键（1…0、q…p、a…;、z…/）按半音顺序排列，每个键对应一个琴键，不用按 Shift。 绿色 = 已弹对，红框 = 弹错过，白色带点 = 当前要弹的音，带下划线 = 超出音域已移八度。如果按键没反应，请切换到英文输入法。

如何阅读乐谱

a s d依次弹奏
[asd]同时按下（和弦）
[a s d]快速连续弹奏（琶音）
-停顿一拍，| 停顿两拍

键位

从左到右、从上到下依次是升高半音：1 2 3 … 0 → q w e … p → a s d … ; → z x c … /，共 40 个键。 每首曲子会自动选择最合适的音域（显示在标题下方），超出音域的音会移一个八度。

快捷键

空格自动播放 / 暂停
← →移调 −1 / +1
↑ ↓加速 / 减速
Esc重置
点击乐谱中的音符从该位置开始练习

练习模式：不自动播放时，乐谱会跟随你的弹奏前进，弹对才会进入下一个音。

添加乐谱

粘贴标准 Virtual Piano 格式的乐谱（就是 virtualpianosheet.com 等网站上 “Copy notes” 复制出来的那种，含大写字母和 !@$ 等符号），会自动转换成本程序的 40 键布局。
